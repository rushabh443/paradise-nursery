# Paradise Nursery

Paradise Nursery is a simple online plant shop built with React and Redux Toolkit.

## Features
- Landing page with company name, short description and a "Get Started" button
- Product listing page with 18 houseplants in 3 categories (Air Purifying, Aromatic, Low Light)
- "Add to Cart" buttons that disable after a plant is added
- Navbar with Home, Plants and Cart links and a cart icon showing the item count
- Shopping cart page with quantity controls, delete button, per-plant and total cost
- Checkout button (shows "Coming Soon") and Continue Shopping button

## Run locally
```
npm install
npm run dev
```
